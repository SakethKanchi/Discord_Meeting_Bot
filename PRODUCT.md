# Product

## Register

product

## Users

Discord guild owners and administrators who self-host Parley. They access the admin panel from a desktop browser to configure the bot, review meeting transcripts, manage action items, and search past meetings. They are technical enough to self-host but are in task-completion mode when using this panel — not exploring, not browsing.

## Product Purpose

Parley is a self-hosted Discord meeting notes bot. The web admin panel lets guild owners configure the bot (summarizer model, behavior), browse meeting history and transcripts, manage and filter action-item todos, ask follow-up questions about meetings, and search across all past transcripts. Success: a user finds what they need in one flow without friction.

## Brand Personality

Precise, reliable, unobtrusive. The tool disappears into the task.

## Anti-references

- Slack's heavy chrome and notification overload
- Notion's infinite-canvas complexity
- Airtable's spreadsheet-everything aesthetic
- Any SaaS-cream palette or gradient-text hero

## Design Principles

1. The tool disappears into the task — no decorative chrome, no choreography.
2. Information density over whitespace theater — compact tables and lists beat airy card grids.
3. One consistent component vocabulary — same buttons, same form controls, same affordances everywhere.
4. State-rich feedback — every action has a visible loading, error, and success state.
5. Dark by default, light when needed — the dark mode is the primary experience; light mode is an equally polished alternative.

## Accessibility & Inclusion

WCAG AA minimum. Body text 4.5:1 contrast. Interactive elements 3:1. Reduced-motion respected.
